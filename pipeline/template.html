Cómo se mantiene al día

Descarga directa de la fuente

Un script por destino baja el archivo oficial (Excel, PDF, API o CSV) desde la URL del organismo y lo procesa. No se usan agregadores ni prensa.

Validación

Antes de publicar, cada serie se contrasta con los totales anuales que publica la misma fuente. Si una cifra no cuadra, esa actualización se detiene.

Revisión semanal

Una tarea automática revisa cada semana si hay publicaciones nuevas y actualiza esta página. Las cifras preliminares se reemplazan cuando el organismo las revisa.
